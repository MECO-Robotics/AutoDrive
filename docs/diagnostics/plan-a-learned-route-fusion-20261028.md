# Experimental learned-cost route fusion

The `AUTODRIVE_EXPERIMENTAL_LEARNED_ROUTE_FUSION=1` switch lets the existing HIP Bellman and lattice extraction kernel handle learned traversal costs. It keeps learned paths unshortcutted. The default remains the prior learned-cost route.

A guarded `pickup_simple/single` seed 71 comparison on an exclusively leased WX 9100 used a real 12,096-node pose graph with a synthetic support mask. The unfused warm route stage took 1.431 s; fused calls took 0.611 and 0.584 s. The first unfused call took 20.214 s with initialization. All route fields, masks, fallback and route evidence digest matched exactly. This is one warm baseline, not an end-to-end training measurement.

Four HIP planner parity cases cover zero, gradient, barrier and near-tie learned maps with multiple starts, headings, robot footprints, obstacles and an inactive row. A production A1 update-16 to update-17 fixture on seed `2970053994459693056` also matched all nine route output hashes across 33 calls. With route batch 2048, steady route-support median changed from 411.26 ms to 376.66 ms and decision median from 456.20 ms to 421.49 ms. The 10%-trimmed route-support mean improved by 7.2%; this is a modest end-to-end gain, not a 2x speedup. Paired reports are under `AutoDriveCampaigns/meco-full-match-offense-production-20261030-0f13e5bd3/profiling/learned-fusion-{baseline,candidate}-20261030.json`.

The production-fixture comparison is diagnostic only. A fresh 12-tick full-match simulator replay was generated with the diagnostic source-rebound checkpoint clone on seed `2970053994459693056`; replay IDs are `scenario-meco-108c3248a1a4e81482bf0219` (A1) and `scenario-meco-ed4f6730771c710e1cd5e244` (A1_P0). Both replay records report current source provenance. The dashboard backend and frontend were verified against this checkout after restart. This short replay did not exercise a route traversal, so it does not establish full-horizon production behavior. Keep the switch opt-in pending that validation and broader parity evidence.
